Reference values for the statistics come from SciPy 1.18 (scipy.stats, scipy.special). The site computes the normal distribution with the Abramowitz & Stegun approximation (error below 1.5 × 10⁻⁷), so p-values are compared within that precision. Network tests need an internet connection and can fail if a NASA service is busy; they do not affect the site. Code: github.com/vivivarm/NEAR.
